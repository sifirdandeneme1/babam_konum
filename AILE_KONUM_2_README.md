# Aile Konum 2 - Firebase deneme dali

Bu dal, mevcut main ve calisan Aile Konum v1 uygulamasindan ayridir. Android paket adi com.omer.ailekonum2.

Kaynak: aile-konum2-source.zip. GitHub Actions: Build Aile Konum 2 (Firebase test APK).

**ONEMLI:** Bu yapi GitHub'da derlense de OPPO telefonda uzun sure test edilmeden guvenilir sayilmamalidir. Debug APK CI'da gecici imza ile uretilir. Kalici surum icin sabit korunan release imzasi gerekir.

Firebase hesabi sifrelerini ve 40 haneli paylasim anahtarini kaynak koduna koymayin.
